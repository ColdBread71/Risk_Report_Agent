# TARA 规范

## 1. 目的

本文档定义第二阶段分析模块使用的 TARA 方法论和输入输出契约。

## 2. 核心思路

- 基于已经抽取出的产品上下文进行威胁分析。
- 将产品功能展开为潜在威胁场景。
- 威胁分类遵循选定的方法论，必要时采用 STRIDE 风格分类。
- 风险评分遵循业务已有的 TARA / DREAD 逻辑。

## 3. 必须包含的内容

- 威胁场景生成原则
- 风险类型分类规则
- 评分维度和解释方式
- 法规映射原则
- 每条风险结论所需的证据要求

## 4. 硬约束

- 不得凭空补出产品没有描述过的行为。
- 不得把弱证据升级成强结论。
- 不得把 Excel 里的方法学备注当成代码逻辑。
- 所有规则都应该写成可复用的文档或配置。

## 5. 与其他文档的关系

- 输入契约定义在 `01_context_spec.md`。
- 上下文来源结构定义在 `01_input_spec.md`。
- 证据引用格式与 `03_evidence_policy.md` 保持一致。

## 6. 输出契约

第二阶段输出应满足 `TaraReport` 的结构要求，并能映射到现有的 Excel 风险表。
